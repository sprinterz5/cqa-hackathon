# Журнал проверок

Каждая проверка гипотезы или допущения — отдельная запись: что проверяли, на каких данных, результат, вывод.
Ссылайтесь на ID из [hypotheses.md](hypotheses.md) и обновляйте там статус.

Шаблон:

```
## E<N>. <коротко> — <дата>
Гипотеза: <ID>
Что сделали: …
Данные: …
Результат: …
Вывод / что меняем: …
```
